# 02 · 디자인 가이드 — 츄블리아이래쉬 (CHUVELY EYELASH)

> 개발 에이전트는 이 문서만 보고 단일 HTML 시안을 구현한다. 값은 그대로 CSS 변수로 옮길 것.
> 2026-09-30 개정: 사장님 레퍼런스(속눈썹 연장 프로모션 배너 3장) 스타일로 전면 리디자인.

## 1. 브랜드 콘셉트
- **한 줄**: "러블리하게 올라가는 컬, 0.01mm까지 재는 손끝"
- **무드**: 피치 블러시 프로모션 배너 — 초콜릿 브라운 콘덴스드 대문자 + 골드 필기체 악센트 + 코랄 꽃·속눈썹 스트립·골드 핀셋 장식.
- **단일 라이트 룩**: 다크 모드 없음(미디어쿼리·`[data-theme]`·테마 토글 모두 제거). `:root`에 `color-scheme: light`, body 배경 명시.
- **금지**: 초록(네이버 브랜드색 포함) CTA, 보라-파랑 그라데이션, 이모지 마커, 외부 이미지 파일, 과한 장식(히어로·할인 배너 외 섹션은 꽃 1개 + 골드 점 몇 개까지).

- 그림자: 카드 `0 4px 14px rgba(59,31,27,.08)`, 배너·영수증 `0 10px 28px rgba(59,31,27,.12)`, 장식 SVG `drop-shadow(0 8px 10px rgba(59,31,27,.18))`.

## 4. 장식 요소 (인라인 SVG 스프라이트, 이미지 파일 없음)
문서 상단 `<svg class="sprite">`(크기 0, display:none 금지 — 그라데이션 참조 유지)에 `<symbol>` 정의 후 `<use href="#…">`로 재사용.
- `#d-lash` 속눈썹 스트립: 위로 휜 밴드(4.5px) + 44가닥 곡선이 부채꼴로 바깥쪽(끝으로 갈수록 길고 바깥으로 쓸림), 굵기 1.35/0.85 교차, 초콜릿.
- `#d-flower` 5장 꽃: 끝이 파인 꽃잎 × 72° 회전, 라디얼 그라데이션 `#EE8B7F → #F4A79D → #FCD8CF`, 가운데 골드 원 + 골드 수술 점.
- `#d-tweezer` 핀셋: 초콜릿 그라데이션 두 팔 + 골드 팁 + 골드 밴드.
- `#d-gift` 흰 원형 선물상자: 원통형 몸통(그라데이션 음영) + 로즈 리본 + 코랄 리본 고리.
- `#d-spark` 4각 골드 반짝이, `#d-dot` 골드 점, `#d-strand` 흩어진 속눈썹 한 가닥.
- **배치 규칙**: 장식은 `.deco`(absolute, `pointer-events:none`) 안, 배너는 `overflow:hidden` — 가로 스크롤 금지. 히어로·할인 배너에 풍성하게(좌우 속눈썹 스트립, 꽃 2–4, 선물상자, 핀셋, 반짝이 6, 점 4, 가닥 3). 일반 섹션은 `.lane-deco`(우상단 패딩 영역): 꽃 1 + 반짝이 1 + 점 1–2.
- **모바일(≤960/≤760px)**: 배너 상하 패딩을 키워(모바일 122px/124px) 속눈썹 스트립은 위 띠, 꽃·선물·핀셋은 아래 띠에만 배치 → 글자를 가리지 않음. 작은 장식 일부 숨김.

## 5. 레이아웃
- 컨테이너 max 1200px, 좌우 패딩 24px(모바일 16px), 섹션 간격 88px(모바일 60px). 텍스트 담는 flex/grid 자식 `min-width:0`.
- 섹션 구분: 가운데로 모이는 로즈 헤어라인 + 중앙 골드 마름모.
- 섹션 헤드: (선택) 대시+자간 넓은 kicker → Black Han Sans h2 → 골드 필기체 한 단어(제목 아래 겹침) → 설명.
- **배너**: 10px 살구 프레임(모바일 6px), 반경 28px, blush+점 패턴, 가운데 정렬. 하단 물결(scallop) 24px 반원 반복.
  - 히어로: `SPECIAL OFFER`(양옆 가는 선) → 가는 선 → `CHUVELY / EYELASH` → 필기체 `Lash Studio` → 가는 선 → `츄블리아이래쉬 · 눈을 뜰 때마다, 츄블리하게.` → `— 첫 방문 20% 할인 —` → 알약 버튼 [N 네이버 예약하기] [시술 보기].
  - 할인 배너: `FIRST VISIT` → `20% OFF` → `Welcome` → `— 첫방문 20% 할인 —` → [네이버 예약하기] [미리보기에 쿠폰 적용].
- 홈 순서: 히어로 → 할인 배너 → 컬 가이드(컬 게이지) → 대표 시술 → 후기 → 래쉬 노트 → 매장 정보(네이버 지도 링크).

## 6. 컴포넌트 규칙
- **버튼**: 모두 알약형(999px), 높이 48(sm 40)px. Primary = 초콜릿 채움 + `#FFF8F5` 글자 + 그림자, 호버 로즈골드 채움 + 초콜릿 글자. Secondary = 투명 + 1px 초콜릿 테두리("VISIT NOW" 스타일). Text = 로즈 밑줄(호버 골드). Disabled = `--line` 면.
- **네이버 예약 CTA**: 초록 금지. 초콜릿 알약 + 왼쪽 20px 골드 사각 `N` 배지(`.nmark`). `<a data-naver target="_blank" rel="noopener">` — href는 JS 상수 `NAVER_PLACE_URL` 하나에서 주입. 위치: 헤더, 히어로, 할인 배너, 컬 가이드, 가격표 각 행, 대표 시술 카드, 매장 정보, 모바일 하단 바, 예약 미리보기 상단, 푸터.
- **카드**: `#FFF8F5` 면 + 1px 로즈 테두리 + 반경 18px(모바일 16px) + 부드러운 그림자 + 하단 골드→브라운 띠.
- **칩/슬롯/탭/카테고리**: 기본 흰 면 + 로즈 테두리 알약. 선택 = 초콜릿 채움 + 흰 글자(컬 아이콘은 골드). 옵션 카드 선택 = `--rose-soft` 면 + 1.5px 초콜릿 테두리 + 왼쪽 골드 4px 인셋.
- **컬 게이지**: 카드 안 SVG, 선 초콜릿(0.8–1.6px 차등), 선택 컬은 골드 그라데이션 2.4px + 골드 라벨. 눈금자 로즈. 컬 버튼은 48px 원형, 선택 시 초콜릿+골드 글자.
- **단계 표시기**: 34px 원형 번호(Montserrat). 현재 = 초콜릿 채움+골드 숫자+로즈 헤일로, 완료 = 로즈골드 채움 + 초콜릿 실선, 대기 = 로즈 점선.
- **캘린더**: 카드 면 위 7열, 원형 날짜. 오늘 = 골드 밑줄, 선택 = 초콜릿 채움. 마감 슬롯은 사선 패턴+취소선, 잔여 1자리는 골드 점.
- **폼**: 언더라인 입력(로즈 1px → 포커스 초콜릿 2px), textarea는 둥근 카드형. 에러 `--accent-ink`.
- **후기 카드**: 카드형 + 골드 별점, 사장님 답글은 blush 면 + 로즈 왼쪽 선. 별점 분포 바는 골드→브라운 띠.
- **매거진 카드**: 카드형, 16:9 살구 그라데이션+점 패턴 플레이스홀더, NEW = 초콜릿 알약+골드 글자.
- **마이페이지**: 프로필 카드(골드 링 아바타), 리터치 박스 로즈 그라데이션, 탭은 알약 칩.
- **푸터**: 초콜릿 배경 + 상단 골드→브라운 띠, 로고 Oswald + 골드 필기체.
- **모바일 하단 바**: 카드 면 + 상단 3px 띠, 좌 정보 / 우 60% 폭 [N 네이버 예약하기]. 예약 미리보기 화면에서만 `다음 단계` 버튼으로 교체. `env(safe-area-inset-bottom)` 유지.
- **토스트**: 초콜릿 알약, 골드 컬 아이콘, `role="status"`.

## 7. 예약 정책 표기
- 실제 예약은 **네이버 예약** (`https://map.naver.com/p/entry/place/1214134647`).
- 사이트 5단계 예약은 "사이트 예약 (준비 중 · 미리보기)"로 유지. 상단에 "현재 예약은 네이버 예약으로 받고 있어요" 안내 카드 + 네이버 버튼.
- 주소·전화·인스타는 확인 전이므로 "(예시)" 라벨 유지.

## 8. 모션·접근성
- 등장 translateY(8px)+opacity 240ms, 선택·호버 120–160ms, 컬 게이지 최초 1회 드로잉. 무한 루프 애니메이션 금지.
- `prefers-reduced-motion: reduce` → 모든 애니메이션·트랜지션 0.01ms, 곡선 즉시 완성.
- 첫 화면 콘텐츠 opacity:0 금지, 장식 SVG `aria-hidden`, 터치 타깃 44px 이상, sticky 헤더 `top: env(safe-area-inset-top, 0px)`, `el.hidden` 사용, alert/confirm/prompt 금지.

## 9. 카피 톤
- 친근한 존댓말 + 숫자로 말하는 전문성. 과장 형용사 금지.
- CTA: `네이버 예약하기` · `시술 보기` · `미리보기에 쿠폰 적용` · `오늘 가능한 시간 (미리보기)` · `결제하고 확정하기`
- 마이크로카피: 빈 후기 "아직 첫 후기를 기다리는 중이에요." / 완료 토스트 "10월 3일 14:30, 자리 맡아두었어요."
