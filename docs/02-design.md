# 02 · 디자인 가이드 — 츄블리속눈썹 (CHUVELY LASH)

> 개발 에이전트는 이 문서만 보고 단일 HTML 시안을 구현한다. 값은 그대로 CSS 변수로 옮길 것.

## 1. 브랜드 콘셉트
- **한 줄**: "러블리하게 올라가는 컬, 0.01mm까지 재는 손끝" — 귀여운 이름 뒤에 래쉬 트레이처럼 정리된 정밀함.
- **무드 키워드**: 체리 포인트 · 스틸 핀셋 · 트레이 라벨 · 곡선(컬) · 정돈된 여백 · 속삭이는 위트
- **소재 원천**: 컬 타입(J/B/C/D/L), 모 두께(0.05–0.15mm), 길이(8–15mm), 래쉬 트레이 라벨, 핀셋, 아이 젤패치.
- **금지**: 핑크 일색, 크림+세리프+테라코타, 보라-파랑 그라데이션, Inter, 이모지 마커, 전면 가운데정렬, 모든 카드 둥근모서리+그림자.

## 2. 컬러 토큰
핑크는 "젤패치" 한 가지로만 소량 사용. 주 포인트는 체리 레드, 구조는 잉크+스틸.

| 토큰 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--bg` (Tray) | `#F1F3F2` 쿨 실리콘 그레이 | `#141317` 잉크 블랙 | 페이지 배경 |
| `--surface` | `#FFFFFF` | `#1F1D23` (배경보다 한 단계 밝게) | 카드·시트·캘린더 |
| `--ink` (Lash) | `#1B1A1F` | `#ECE8EC` | 본문·헤드라인·아이콘 |
| `--steel` (Tweezer) | `#7D858C` | `#9AA2A9` | 보조 텍스트, 라벨, 1px 헤어라인(`--line`: 라이트 `#D5DAD8` / 다크 `#34313A`) |
| `--cherry` (Accent) | `#D72A4A` | `#FF5C76` (다크에서 채도 유지·명도 상승) | CTA, 선택 상태, 시그니처 곡선 강조 |
| `--patch` (Gel pad) | `#F6D5DB` | `#3B2530` (어두운 로즈 브라운) | 선택 칩 배경, 후기 하이라이트, 토스트 배경 |

- 다크 모드: `prefers-color-scheme` + `[data-theme]` 토글. 다크에서 `--cherry` 위 텍스트는 `#141317`.
- 대비: `--steel` 텍스트는 14px 이상에서만. 본문은 항상 `--ink`.

## 3. 타이포그래피 (Google Fonts only)
| 역할 | 폰트 | 사용 |
|---|---|---|
| 디스플레이 | **Hahmlet** (300/600) | 한글 헤드라인, 로고 워드마크 `CHUVELY LASH`(300, letter-spacing .24em) |
| 본문 | **IBM Plex Sans KR** (400/500/600) | 본문, 버튼, 폼 |
| 유틸리티 | **IBM Plex Mono** (400/500) | 가격, mm·컬 스펙, 날짜/시간, 단계 번호, 라벨 (숫자·영문만) |

타입 스케일 (base 16px, 비율 ~1.25, 모바일은 괄호 값):
- `display` 56px/3.5rem (36px) · lh 1.15 · Hahmlet 300, 강조 단어만 600+cherry
- `h1` 40px/2.5rem (28px) · `h2` 28px/1.75rem (22px) · `h3` 20px/1.25rem (18px)
- `body` 16px/1rem · lh 1.7 · `small` 14px/.875rem
- `label` 12px/.75rem · Plex Mono 500 · uppercase · letter-spacing .12em (예: `C CURL · 0.07MM · 11MM`)
- `price` 20px Plex Mono 500, 단위 "원"은 본문 폰트 14px steel

## 4. 레이아웃
**콘셉트: "래쉬 트레이 레인"** — 섹션은 트레이의 가로 줄처럼 1px 헤어라인으로 나뉜 레인. 각 레인 좌측에 mm 눈금 같은 Mono 라벨(`08`, `09`…섹션 번호 대신 모 길이)을 붙이고, 콘텐츠는 **좌측 정렬 비대칭 그리드**(12col, 라벨 2 : 콘텐츠 10).

- 컨테이너 max 1200px, 좌우 패딩 24px(모바일 16px), 레인 간격 96px(모바일 56px).
- 헤더: 좌 워드마크 / 우 메뉴(시술·가격, 예약, 후기, 매거진, 마이) + `예약하기` 버튼. 스크롤 시 배경 `--bg` 92% + 하단 헤어라인.

섹션 스케치:
```
[HOME/HERO]  label "08mm" | 좌 7col: display 헤드라인 + 서브 + CTA 2개
                          | 우 5col: 시그니처 컬 게이지 SVG (큰 사이즈), 아래 스펙 라벨
[시술 하이라이트] 가로 스크롤 트레이: 시술 카드 4~6개 (각 카드 상단에 컬 아이콘+스펙 라벨)
[시술·가격]  좌: 카테고리 탭(세로, 모바일은 가로 칩) | 우: 표 형식 리스트
             행 = 시술명 / 스펙 라벨 / 소요시간(Mono) / 가격(Mono, 우측정렬) — 카드 아님, 헤어라인 행
[예약]       상단 단계 표시기(01–05) | 본문 좌 8col 단계 폼 | 우 4col 스티키 "예약 요약 영수증"
[후기]       상단 필터 칩(시술/별점/사진만) + 정렬 | 2열 매스너리(모바일 1열)
[매거진]     첫 기사 와이드(8col) + 나머지 리스트(4col), "매일 07:00 업데이트" Mono 라벨
[마이페이지]  좌 프로필·등급·다음 예약 카드 | 우 탭: 예약내역 / 내 후기 / 나의 래쉬 레시피(지난 스펙 기록)
[푸터]       잉크 배경 반전 블록, 주소·영업시간 Mono, 인스타 링크 텍스트
```

**모바일(≤400px) 규칙**
- 1열, 레인 라벨은 콘텐츠 위 한 줄로 이동. 헤더 메뉴는 햄버거 → 전체화면 시트.
- **하단 고정 예약 바**: 높이 64px + `env(safe-area-inset-bottom)`, `--surface` 배경·상단 헤어라인, 좌 "오늘 가능 3자리"(Mono small) / 우 cherry 버튼 `예약하기`(폭 60%). 예약 플로우 내부에서는 "다음 단계" 버튼으로 교체. 본문 하단 패딩 80px 확보.
- 터치 타깃 최소 44px, 가로 스크롤 트레이는 `scroll-snap-type: x mandatory`, 다음 카드 20% 노출.
- 가격 표는 2줄 행(시술명+가격 / 스펙+시간)으로 접기.

## 5. 시그니처 그래픽 — "컬 게이지 (Curl Gauge)"
인라인 SVG. 하나의 기준점(모근)에서 J·B·C·D·L 5개의 곡선이 부채꼴로 뻗는 다이어그램, 각 끝에 Mono 라벨.
- 선: `stroke: var(--ink)`, 두께를 실제 모 두께처럼 0.8/1.0/1.2/1.4/1.6px로 차등, `stroke-linecap: round`, fill 없음.
- 선택/강조 컬 하나만 `--cherry` 2px. 하단에 눈금자(1mm 간격 tick, 5mm마다 긴 tick).
- 경로 예시(viewBox 0 0 200 120, 기준점 20,110): J `M20 110 Q120 105 170 60` / C `M20 110 Q110 110 150 30` / L `M20 110 L90 100 Q140 90 150 20` 등 컬이 강할수록 끝이 더 위로 말림.
- 재사용: 히어로(대형), 시술 칩 아이콘(단일 곡선 24px), 섹션 구분선(짧은 J 곡선 + 헤어라인), 로딩 스피너(곡선 드로잉).

**사진 플레이스홀더**: 이미지 파일 없이 `--patch`→`--bg` 방향 `linear-gradient(160deg)` 위에 `repeating-linear-gradient(100deg, transparent 0 6px, rgba(27,26,31,.06) 6px 7px)`의 미세 사선(속눈썹 결)을 겹침. 좌하단에 Mono 라벨(`PHOTO · C 0.07 11MM`). 비율 4:5(후기·시술), 16:9(매거진).

## 6. 컴포넌트 규칙
공통: 모서리 반경 **2px 기본**, 둥근 형태는 칩(pill)과 아바타에만. 그림자는 스티키/오버레이 요소(하단 바, 토스트, 모달)에만 `0 8px 24px rgba(20,19,23,.12)`. 카드는 1px `--line` 테두리로 구분.

- **버튼**: Primary = cherry 배경/흰 텍스트, 높이 48px, 좌우 24px, 600. Secondary = 투명+1px ink 테두리. Text = 밑줄 오프셋 4px. Hover: Primary는 명도 -8%, 우측 화살표 `→` 4px 이동. Disabled: `--line` 배경, steel 텍스트.
- **칩(시술 선택)**: pill, 높이 36px, 1px `--line`. 좌측에 24px 컬 아이콘. 선택 시 `--patch` 배경 + cherry 1.5px 테두리 + 체크 대신 곡선이 cherry로 변함. 다중 스펙은 Mono label로 `C · 0.07 · 11mm`.
- **예약 캘린더**: 7열 그리드, 날짜는 Mono 16px, 정사각 셀 테두리 없음. 오늘 = 숫자 아래 cherry 2px 밑줄, 선택 = ink 배경/반전 텍스트, 휴무 = steel + 취소선. 월 이동은 좌측정렬 헤더 `2026.10` + 화살표.
- **타임슬롯**: 3열(모바일) / 5열 버튼, Mono `14:30`, 높이 44px. 마감 슬롯은 사선 패턴 배경+비활성, 잔여 1자리는 우상단 cherry 점. 오전/오후 그룹 라벨.
- **디자이너 선택**: 가로 카드(아바타 원형 56px + 이름 + "주력 컬: C·D" 라벨 + 후기 수), 라디오 행 방식.
- **후기 카드**: 상단 별점(SVG 별 5개, 채움 cherry, 14px) + 날짜 Mono, 사진 플레이스홀더(있을 때), 본문 4줄 클램프 + "더보기", 하단 스펙 라벨·디자이너명. 테두리 대신 좌측 2px ink 세로선으로 인용 느낌.
- **매거진 카드**: 16:9 플레이스홀더, 카테고리 label(`LASH CARE`/`BEAUTY`), 제목 Hahmlet 20px 2줄, 3줄 요약, 하단 `출처 · 2026.09.30 · 3분` Mono. 신규(24시간 내)는 제목 앞 cherry `NEW` 라벨.
- **단계 표시기**: `01 시술 — 02 디자이너 — 03 일정 — 04 정보 — 05 결제`. 번호 Mono, 완료 = ink 실선 연결 + 번호 클릭 가능, 현재 = cherry 번호+굵은 라벨, 대기 = steel 점선. 모바일은 번호만 표시 + 현재 단계명 한 줄.
- **예약 요약(영수증)**: 점선 구분, 항목·값 좌우정렬, 합계 Mono 24px. 모바일은 하단 바 위 접이식 시트.
- **폼 입력**: 높이 48px, 하단 1px 테두리만(언더라인형), 포커스 시 cherry 2px. 에러 문구 13px cherry.
- **토스트**: 화면 하단(모바일은 예약 바 위 12px) 좌측 정렬, `--ink` 배경·`--bg` 텍스트, 좌측에 짧은 cherry 컬 곡선 아이콘, 3초 자동 닫힘, `role="status"`.

## 7. 모션 원칙
1. **"컬이 올라간다"**: 등장 요소는 translateY(8px)→0 + opacity, 240ms `cubic-bezier(.2,.8,.2,1)`. 시그니처 곡선만 최초 1회 `stroke-dashoffset` 드로잉 900ms.
2. **상태 변화는 짧게**: 선택·호버 120–160ms, 색/테두리만 전환. 페이지 스크롤 패럴랙스·무한 루프 애니메이션 금지.
- `@media (prefers-reduced-motion: reduce)`: 모든 transition/animation 0.01ms, 곡선은 완성 상태로 즉시 표시.

## 8. 카피 톤 & 예시
- **톤**: 친근한 존댓말 + 숫자로 말하는 전문성. 귀여움은 한 문장에 한 번만. 과장 형용사("최고의", "완벽한") 금지.
- **히어로 헤드라인**
  - A안: "눈을 뜰 때마다, **츄블리**하게." / 서브: "C컬 0.07mm부터 L컬까지, 당신 눈매에 맞춰 한 가닥씩 계산합니다."
  - B안: "한 가닥 0.07mm, 차이는 **컬**에서." / 서브: "러블리한 눈매를 오래 가게 만드는 건 결국 정교한 손끝이에요."
- **CTA**: `예약하기` · `오늘 가능한 시간 보기` · `내 눈에 맞는 컬 찾기` · `이 디자이너로 예약` · `결제하고 확정하기`
- **마이크로카피**
  - 빈 후기: "아직 첫 후기를 기다리는 중이에요."
  - 예약 완료 토스트: "10월 3일 14:30, 자리 맡아두었어요."
  - 마감 슬롯: "이 시간은 마감됐어요. 가까운 시간을 보여드릴게요."
  - 매거진 헤더: "오늘의 래쉬 노트 — 매일 아침 7시에 새로 정리해요."
